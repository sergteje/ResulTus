This package implements the `[ErrorFactory]` partial methods declared on a type marked
`[ResultErrors]`, so a [ResulTus](https://github.com/sergteje/ResulTus) error code, category and
message template are written once and reused. It is an incremental generator: an edit re-runs only
the declaration that changed, and a build produces the same files either way. Both attributes ship
in the `ResulTus` package; this package supplies the method bodies.

## Install

```bash
dotnet add package ResulTus.SourceGenerators
```

## Dependencies

- [`ResulTus`](https://github.com/sergteje/ResulTus/blob/main/src/ResulTus/README.md) — required in
  your project: it carries the `Error` type and the `[ResultErrors]`/`[ErrorFactory]` attributes this
  package implements against.

This package declares no package dependency of its own, and `ResulTus` does not reference it, so add
it explicitly. Its reference to the Roslyn API (`Microsoft.CodeAnalysis.CSharp`) is private and
never enters your package graph.

## What you get

`ErrorFactoryGenerator` and one diagnostic, `RESULTGEN001` (Error), reported when a
`[ErrorFactory]` declaration cannot be generated.

Declare the error as a `static partial` method that returns `Error` on a `partial` type marked
`[ResultErrors]`:

```csharp
using System;
using ResulTus;

[ResultErrors]
public static partial class UserErrors
{
    [ErrorFactory("USER_NOT_FOUND", ErrorType.NotFound, "User {id} not found")]
    public static partial Error NotFound(Guid id);

    [ErrorFactory("INVALID_EMAIL", ErrorType.Validation, null)]
    public static partial Error InvalidEmail();
}
```

```csharp
using System;
using ResulTus;

Error notFound = UserErrors.NotFound(Guid.NewGuid());
// notFound.Code   == "USER_NOT_FOUND"
// notFound.Type   == ErrorType.NotFound
// notFound.Message == $"User {<the id>} not found"

Error invalid = UserErrors.InvalidEmail();
// invalid.Code == "INVALID_EMAIL", invalid.Message == null
```

`[ErrorFactory(code, type, message)]` supplies the three values the generated body needs. The message
template is emitted as the content of an interpolated string, so `{id}` is the method's `id`
parameter; a literal brace is written `{{` or `}}`, as in any interpolated string. A `null` template
produces an error with no message, which `Error.Message` keeps distinct from an empty one.

## Rules the generator enforces

The generated file is marked `// <auto-generated/>` and writes every type fully qualified. It is a
second part of the annotated type, so the type and every type that encloses it must be `partial` and
must not be `file`-local. The method must be `static partial`, return `ResulTus.Error`, declare no
body and take no `out` parameter, and the category must be a member of `ErrorType` other than
`ErrorType.None` — the absence of an error is a property, not a factory.

A declaration that breaks any of those rules is reported as `RESULTGEN001`, an error naming the
offending member and the reason, never silently skipped. A method carrying `[ErrorFactory]` on a
type without `[ResultErrors]` is reported the same way, because `[ResultErrors]` is the opt-in.
